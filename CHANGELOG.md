# Changelog

All notable changes to this project are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning follows SemVer.

## [1.1.0] - 2026-11-26

### Added
- Open-source packaging: CI workflow (asset check, JS syntax, headless smoke test), `tools/check_assets.py`, `tools/smoke.mjs`.
- Project docs: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, customization guide (`docs/CUSTOMIZATION.md`).
- `package.json` scripts: `serve`, `check`, `smoke`.

## [1.0.0] - 2026-11-26

### Added
- **The Runway Lineup** — six-look runway hero with depth slots, float, breathing floor shadow, click-to-front, swipe/arrow-key navigation, 360° turntable for Look 01 of each cast.
- Fall '26 women's and men's collections — 12 looks, 3 colourways each, per-look colour memory.
- "In this look" panel and "Every piece" grid with wishlist and size-M quick-add.
- Hash-routed product pages (`#look-<id>`) with 360° view, drag-to-spin, size validation, reserve-in-store, accordions, "You may also like" rail.
- Bag drawer with free-shipping progress, quantity steppers, checkout flow, toasts.
- Search overlay, members popover, dark footer, reduced-motion support.
- Ten generated studio cutouts (women 01–06, men 01–04), SVG flat product illustrations, lookbook plates for men's 05/06.
